# Changelog
## 1.2.4 – 2026-11-22
- Fixed: fonts you added now show in the font list straight after the app starts (no need to open *My fonts* first).
- Font list now starts with *Recently used*, and has **＋ Add font…** and **⬇ Get fonts online…** buttons.
- New *Get fonts online*: one-click install of open-licence (SIL OFL) Malayalam fonts, downloaded directly from their public source.

## 1.2.3 – 2026-11-22
- New independently written ML-TT / FML-TT (ISFOC) converter; the old converter was removed. ML and FML share one layout.
- Unicode → Manglish is now a small original rule set.

## 1.2.2 – 2026-11-22
- Removed the separate Handwriting Studio; install your own handwriting font in *My fonts* and use it on the writing pad.
- New: Copy as ML / Copy as FML, and Save plain text as Unicode, ML or FML series.
- Legal review: see LEGAL.md.

## 1.2.1 – 2026-11-22
- Fonts: removed all proprietary legacy fonts; bundled only SIL OFL 1.1 fonts and added Meera, Rachana, Karumbi, Keraleeyam, Dyuthi, Anjali Old Lipi, Uroob, Anek Malayalam and Baloo Chettan 2, with full attributions.

## 1.2.0 – 2026-11-22
- Compact Word-style header: tabs, document name, sections and Save on one row; window buttons in the Windows app.
- On-screen keyboard fits any screen width and stays small.
- Theme colours (7 soft themes + custom), dark mode, interface size, high contrast, reduced motion.
- Accessibility: screen-reader labels and announcements, skip link, read-aloud, keyboard help.
- About dialog with version, update check, credits.
- Objects (picture, text box, line, table) can be resized, moved and rotated; mini floating toolbar; picture effects.
- Document tabs, blank start, zoom slider, rulers on four sides, direct Print.
- Windows app: fonts installer, session restore, Scroll Lock light sync, Manglish layout with suggestion pop-up, refined tray, settings and compact overlays, update from web.
